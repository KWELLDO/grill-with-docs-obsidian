# 种子输入（两遍完全相同）

题目来源：本 Obsidian 库中的 `知识存储与图数据库方案.md`（650 行真实方案）。

方案要点：

- 主张：知识系统不该只存客体化事实，要存「生成条件 + 主体体验 + 自我批判」
- 数据模型三层：对象层 / 主体层 / 反身层
- 节点类型：KnowledgeClaim, ExperientialRecord, Condition, Critique, Reflection
- 存储：Neo4j 存反身关系 + 向量库存体验嵌入 + 文档库存原始证据
- 检索：混合检索 + 反身检索（返回答案时同时返回其条件、批判、体验）
- 机制：每次知识使用后触发「理性回收」；另有周期性批判性审查
- Agent：增加 reflect 工具

## 用户回答脚本（两遍都用）

R1-1 三存储分工：同意
